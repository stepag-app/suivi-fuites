Comment lire le tableau
  • {n}, {date}… sont des valeurs remplies par l'application (nombre, date, numéro). Gardez-les dans vos variantes.
  • « identique à l'arabe » : la phrase ne contient aucun terme du glossaire, le mode hybride affiche donc la version arabe.
  • Si vous décochez un terme du glossaire, je reprendrai les phrases hybrides qui le contiennent : inutile de les corriger une par une.
  • Nouveau : 49 libellés ajoutés par la nouvelle interface de l'APK (écran « Nouveaux libellés », N° Z01 à Z49) attendent votre relecture. Vos validations précédentes sont conservées.
  • Hors de ce dictionnaire : les listes saisies dans le panneau (natures de revêtement, motifs, équipes) et les désignations des articles Dolibarr. Je les traiterai à part.
